# Free-support Wasserstein barycenter replication notebooks

This repository contains reader-facing Quarto notebooks and compiled markdown documents for the paper

> **A Particle-Flow Algorithm for Free-Support Wasserstein Barycenters**

Each example has its own `code-*` directory, a Quarto notebook, an `auxiliary.R` helper file, and the scripts needed by that notebook.

## Composition

There are four compiled notebooks:

- [`sim-gaussian.md`](code-sim-gaussian/sim-gaussian.md), — Gaussian barycenters, step-size sensitivity, runtime scaling, and POT baselines.
- [`sim-wasp.md`](code-sim-wasp/sim-wasp.md) — Bayesian posterior aggregation with Wasserstein barycenters.
- [`real-digits.md`](code-real-digits/real-digits.md) — MNIST digit prototypes and nearest-prototype classification.
- [`real-clustering.md`](code-real-clustering/real-clustering.md) — Distributed vector quantization with barycentric prototypes.

Each notebook can be run from its corresponding Quarto document (`.qmd`), which contains the code and generates the figures and results in the compiled markdown. 
For reproducibility, the notebooks are designed to run in a "smoke test" mode that executes a small subset of tasks and produces a few figures. The full set of computations and figures can be generated by switching to "full" mode. 
This can be set from a user-editable settings cell:

```r
run_mode <- "smoke"       # "smoke" or "full"
run_compute <- TRUE       # FALSE: only make figures from existing results
install_packages <- FALSE # TRUE: attempt to install missing R packages
jobs <- 1L                # use more jobs for full runs
```

Use `smoke` mode first. It checks packages, data paths, computation, saving, assembly, and plotting on a small subset of tasks. Use `full` mode only for the manuscript-scale computations.

## Package installation

Install R packages from within a notebook by setting `install_packages <- TRUE`, or run:

```r
source("install-packages.R")
```

The POT baseline in the Gaussian notebook requires Python packages listed in `requirements.txt`:

```bash
python3 -m pip install -r requirements.txt
```

## Rendering examples

From the repository root:

```bash
quarto render code-sim-gaussian/sim-gaussian.qmd
quarto render code-sim-wasp/sim-wasp.qmd
quarto render code-real-digits/real-digits.qmd
quarto render code-real-clustering/real-clustering.qmd
```

The notebooks render to GitHub-flavored markdown (`.md`) and create local `figures/`, `logs/`, and result folders inside each `code-*` directory.

## Notes on full runs

Full runs use exact OT subproblems and can be expensive. The most computationally demanding pieces are the large-support Gaussian tasks, POT baselines, and the clustering grid. Increase `jobs` only if the machine has sufficient memory and CPU resources.
