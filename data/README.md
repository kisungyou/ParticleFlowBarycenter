# Data folder

Place preprocessed data files here before rendering the notebooks that require them.

Required for `code-sim-wasp/sim-wasp.qmd`:

- `normal-simplified-reduced.RData`

Required for `code-real-clustering/real-clustering.qmd`:

- `processed_pbmc.RData`
- `processed_news.RData`
- `processed_fmnist.RData`

The Gaussian notebook is fully synthetic. The MNIST notebook uses the `digits` data bundled with the `T4transport` package.
